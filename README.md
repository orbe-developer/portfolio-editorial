# portfolio-editorial

Personal portfolio website for Orbehin Sarmiento Barzaga — Senior Backend Engineer based in London.

**Live site:** https://orbe-developer.github.io/portfolio-editorial/

## Design

Editorial style inspired by high-end print design — asymmetric layouts, large serif typography (Playfair Display + Inter), restrained colour palette, and scroll-triggered animations. No frameworks, no dependencies.

## Structure

```
portfolio-editorial/
├── index.html
├── assets/
│   ├── css/styles.css
│   ├── js/main.js
│   └── images/
└── docs/
    └── PORTFOLIO_PROMPT.md
```

## Tech

- Vanilla HTML, CSS, JavaScript
- Google Fonts: Playfair Display + Inter
- IntersectionObserver for scroll animations and active nav highlight
- Mobile: section name indicator instead of hamburger menu
- Deployed via GitHub Pages
